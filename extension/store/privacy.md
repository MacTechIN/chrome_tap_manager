# Chrome Tap Manager 개인정보처리방침 / Privacy Policy

최종 수정: 2026-09-14

## 한국어

Chrome Tap Manager(이하 "확장")는 사용자의 Chrome 창과 탭을 주제별로 정리하고 검색하는 도구입니다.

- **수집하는 정보**: 확장은 열려 있는 창·탭의 제목, URL, 파비콘 URL, 탭 그룹 이름을 읽습니다. 이 정보는 검색 색인과 주제 관리에만 사용됩니다.
- **저장 위치**: 모든 데이터(주제 이름·색상, 규칙, 설정, 최근 이동 기록)는 사용자의 브라우저 안 `chrome.storage.local` / `chrome.storage.session`에만 저장됩니다.
- **전송**: 확장은 어떤 데이터도 외부 서버로 전송하지 않습니다. 원격 코드를 내려받지 않으며, 분석·광고·추적 도구를 포함하지 않습니다.
- **데스크톱 앱 연결(선택)**: 사용자가 설정 페이지에서 "연결 켜기"를 눌러 `nativeMessaging` 권한을 허용한 경우에만, 같은 컴퓨터에 설치된 데스크톱 앱과 로컬로 창·탭 목록을 주고받습니다. 이 통신은 사용자 기기를 벗어나지 않습니다.
- **삭제**: 설정 페이지의 "모든 데이터 초기화" 또는 확장 제거로 모든 데이터가 삭제됩니다.
- **문의**: https://github.com/MacTechIN/chrome_tap_manager/issues

## English

Chrome Tap Manager ("the extension") organizes and searches your Chrome windows and tabs by topic.

- **Data accessed**: titles, URLs, favicon URLs and tab-group names of your open windows and tabs, used only for the search index and topic management.
- **Storage**: everything (topic names and colours, rules, settings, recent move log) is kept in your browser's `chrome.storage.local` / `chrome.storage.session`.
- **Transmission**: the extension sends no data to any server, loads no remote code and contains no analytics, ads or trackers.
- **Desktop app link (optional)**: only if you click "Enable" on the options page and grant the `nativeMessaging` permission, the extension exchanges window/tab lists with the desktop app installed on the same computer. This never leaves your device.
- **Deletion**: "Reset all data" on the options page or uninstalling the extension removes everything.
